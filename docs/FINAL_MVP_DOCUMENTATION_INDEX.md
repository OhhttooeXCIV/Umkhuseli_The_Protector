### Executive Overview

Welcome to the definitive documentation index for **Umkhuseli: The Protector (*Sankofa Safe*)**, submitted for the final evaluation of the **First National Bank App of the Year (FNBAOTY) 2026 Hackathon**.

Umkhuseli is a discreet, low-data, dual-persona emergency response platform and court-admissible legal evidence vault designed specifically for Gender-Based Violence (GBV) and Intimate Partner Violence (IPV) survivors in South Africa. Disguised as **PowerCal SA** (an authentic municipal prepaid electricity calculator) and the **Sankofa Wisdom Launcher** (a daily African proverb home screen), the system delivers life-saving covert emergency alerting, loadshedding-resilient communication, tamper-evident evidence preservation under Section 15 of ECTA (Act 25 of 2002), and statutory court preparation under the Domestic Violence Act (Act 116 of 1998 as amended by Act 14 of 2021).

### Quick Start Guide for Evaluators & Judges

#### Option A: Running the Web PWA Locally
```bash
# Navigate to web directory
cd web

# Install dependencies (if not already installed)
npm install

# Run automated Vitest test suite
npm run test

# Launch local development server
npm run dev
# Open http://localhost:5173 in browser (or private/incognito window)
```

#### Option B: Building Native Android APK
```bash
# In the project root:
./gradlew testDebugUnitTest
./gradlew assembleDebug

# Output APK located at:
# app/build/outputs/apk/debug/app-debug.apk
```

#### Interactive Judge Trigger Codes
When interacting with the *PowerCal SA* municipal prepaid meter calculator:
- **`1234=` or `8426=`**: Unlocks the covert **Umkhuseli Safe Haven** (Vault, SOS, Form 2 DVA Wizard, TCC Navigator).
- **`9999=`**: Triggers the **Duress Coercion Mode**, displaying an authentic *STS ERROR 30* meter fault terminal while silently dispatching an emergency alert with GPS coordinates.
- **Hardware Back / Esc / Double Tap**: Executes a **0-millisecond Panic Scrub**, instantly purging decrypted keys from memory and returning to the electricity meter.
