Security Software Development Lifecycle

SSDL Security Architecture & Compliance

Built according to OWASP Mobile Top 10 and South African POPIA (Protection of Personal Information Act).

Cryptographic Protections

  • Key Generation: 256-bit AES keys generated inside Android Hardware Keystore (StrongBox / TEE).
  • Cipher Mode: Authenticated AES/GCM/NoPadding with unique 12-byte initialization vectors per record.
  • At-Rest Storage: Plaintext descriptions and impacts are never written unencrypted to disk.
  • Biometric Layer: BiometricPrompt with strong hardware verification (Face/Fingerprint/PIN).

Stealth & Memory Hardening

  • Zero-Latency Camouflage: ViewModel state reset clears decrypted memory strings in 0 ms.
  • ProGuard / R8 Obfuscation: Symbols and reflection identifiers obfuscated against decompilation.
  • No Third-Party Analytics: Zero tracking SDKs or ad networks to prevent tracking and location leaks.
  • POPIA Compliance: Local-first storage guarantees the user maintains 100% data sovereignty.

Incident Record Legality (J88 / Form 2 Compliance)

Export routine outputs structured text formatted to match Form 2 (Domestic Violence Act 116 of 1998 / Act 14 of 2021), with timestamped incident numbers, perpetrator names, impact statements, and SAPS OB references for direct submission to the Clerk of the Court.
